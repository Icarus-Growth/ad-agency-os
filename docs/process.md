# How an ads agency runs (the process this OS is built on)

Done-for-you ad management. The database follows the work. If your process is
different, say so before the Interview questions, because a different process
changes the tables.

## 1. Onboarding (clients table, onboarding stage)
0 Paid → 10 Contract Sent → 20 Contract Signed → 30 Set-Up → 40 Call Booked → 50 Call Taken → 100 Onboarded.
Set-Up covers: the client's Slack channel, the shared folder, the onboarding form, and access to the client's ad account.

## 2. Creatives (the Editing pipeline board)
Write the script → script review → script changes (bounce-back) → wait for the client's footage → edit →
redo (bounce-back) → internal review → client changes (bounce-back) → client review → ready to launch → launched.
One card is one ad, from script to launched. Each creative can name the ad campaign it runs in.

## 3. Ad campaigns (the Campaigns board)
Backlog → planning → building → client approval → ready to launch → live → optimising → ended.
One card is one ad campaign for one client. A live or optimising campaign is not finished.
It stays on My Work until it ends ("100 - Ended").

## 4. Reporting (daily and weekly numbers)
Spend, leads, cost per lead and calls booked, per client, per day and per week.

## 5. Everything else (the Tasks board)
Any one-off job for anyone. Stages: -1 Rejected (will not be done), 0 Backlog, 9 Blocked, 10 In Progress, 29 Amendments, 30 In Review, 100 Complete.
